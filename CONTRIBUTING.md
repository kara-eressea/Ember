# Contributing

Thanks for your interest in EmberChat — but please read this before opening anything.

## This project does not accept unsolicited contributions

EmberChat is a personal project developed on a fixed roadmap (see
[`design/milestones.md`](design/milestones.md)). It is open source so that
people can read it, learn from it, fork it, and self-host it — **not** because
it is seeking contributors.

Concretely:

- **Pull requests are not accepted.** Unsolicited PRs will be closed without
  review. If you have a fix you rely on, please carry it in your own fork.
- **Feature requests are not taken.** The roadmap is set and worked in order.
- **Bug reports** for genuine defects are welcome as issues (if issues are
  enabled), but there is no support commitment or response-time expectation.

## Please do not contact the author about this repository

No unsolicited email, sales outreach, recruiting, "partnership" proposals, or
offers of services related to this repository. Such messages will not receive
a reply. This explicitly includes automated or AI-personalized outreach based
on the contents of this repo.

## Security issues

If you find a security vulnerability, a private report is the one kind of
contact that is welcome — please use GitHub's private vulnerability reporting
("Report a vulnerability" under the Security tab) rather than a public issue.

## Forks

Forking is fine and encouraged — that's what the MIT license is for. You do
not need permission, and you do not need to tell the author.
